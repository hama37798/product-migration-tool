# 商品マスタ移行ツール

商品の販売管理システムへの導入を想定した、
商品マスタのCSV移行を行う学習用ポートフォリオです。

移行前のデータチェック、SQLによる登録、実行ログの保存、
AWS S3へのログ送信、APIによる登録内容の参照を実装しています。

## 作成の目的

システム導入時のデータ移行で、入力不備や二重登録を検出し、
利用者が修正箇所を確認できる仕組みを学ぶために作成しました。

## 使用技術

- C# / .NET 10
- SQLite / Microsoft.Data.Sqlite
- ASP.NET Core Minimal API
- AWS S3 / AWS SDK for .NET
- Git / GitHub

## 主な機能

- CSVの商品コード・商品名の必須チェック
- 単価・在庫数量の整数チェック、負数チェック
- CSV内およびDB内の商品コード重複チェック
- エラー行の行番号と理由の表示
- 検証エラーがある場合、CSVからの登録を全件中止
- トランザクションを使った一括登録
- SQLによる在庫金額の計算
- 開始・終了時刻付きのUTF-8ログ保存
- オプション指定によるS3へのログ送信
- 読み取り専用の商品一覧API

## 実行方法

.NET 10 SDKが必要です。
以下はプロジェクトのフォルダーで実行します。

### CSVチェック・登録

    dotnet run

初回実行時にproducts.dbと商品テーブルを作成し、
サンプル商品3件を登録します。
続いてproducts.csvを検証し、問題がなければ登録します。

同じCSVを再実行した場合は、登録済みの商品コードを検出し、
CSVからの追加登録を中止します。

コンソールの商品一覧は、CSV登録前の「在庫数量5以下」の商品です。

### 商品一覧API

先にdotnet runでDBを作成してから起動します。

    dotnet run -- --api

ブラウザーで次のURLを開きます。

    http://localhost:5050/products

全商品のコード、名称、単価、在庫数量、在庫金額を
件数とともにJSON形式で返します。

APIはlocalhostで待ち受けます。停止はCtrl+Cです。
APIモードではCSV移行とS3送信は実行しません。

### S3へのログ送信

    dotnet run -- --upload-s3

事前にAWSの認証設定と、保存先バケットへの
書き込み権限が必要です。

現在のコードでは、保存先バケット名・リージョン・
認証プロファイル名をProgram.csに指定しています。
別の環境で使う場合は、自分の設定に変更してください。

S3送信に失敗してもローカルのログは残り、
すでに終了したDB処理の結果は変更しません。

AWSを利用しない通常実行とAPI起動には、AWS認証は不要です。

## CSV形式

UTF-8のCSVファイルを使用します。
先頭行を見出しとして扱い、2行目から読み込みます。

    product_code,product_name,unit_price,stock_quantity
    G006,強化ガラス,6000,8
    G007,合わせガラス,8500,4

単価と在庫数量は、0以上の32ビット整数を指定します。
サンプルの商品・価格は架空のデータです。

## 動作確認済み

- 正常なCSV4件のDB登録
- CSV内の商品コード重複の検出
- DBに登録済みの商品コードの検出
- 検証エラー時のCSV登録中止
- 日本語のUTF-8ログ保存
- C#からS3へのログ送信
- 商品一覧APIで11件取得、HTTP 200で応答
- API追加後も従来のCSVチェックが動作すること
